description: Prompt 2: Technical architecture
---

Analyze every paper in the research folder using the same extraction schema.

For each paper identify:

1. Input modality
2. Camera type
3. Camera placement/viewpoint
4. Person detection method
5. Person tracking method
6. Pose estimation method
7. Feature extraction
8. Motion features
9. Spatial features
10. Temporal features
11. Classification model
12. Temporal model
13. Fall-decision logic
14. Confidence/threshold mechanism
15. False-positive reduction mechanism
16. Multiple-person handling
17. Occlusion handling
18. Lighting variation handling
19. Camera-angle variation
20. Staircase handling
21. Real-time implementation
22. Hardware
23. Software/frameworks
24. Computational requirements

For each field use:

* specific method/model
* whether it is explicitly stated
* page/section reference

If a paper does not mention a feature, write "Not reported".

Do not assume that absence of discussion means the system cannot perform the feature.

Produce:

A. Individual paper records
B. A cross-paper comparison matrix
C. Frequency counts showing how often each technical approach occurs.
