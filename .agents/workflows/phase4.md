---
description: Prompt 4: Performance
---

Extract the quantitative experimental results from every paper.

For each paper collect, where available:

* Accuracy
* Precision
* Recall
* Sensitivity
* Specificity
* F1-score
* False-positive rate
* False-negative rate
* AUC
* Detection rate
* Miss rate
* FPS
* Inference latency
* Processing time
* Computational requirements

Also identify:

* Baseline methods
* Ablation studies
* Dataset used for evaluation
* Number of test samples/videos
* Whether evaluation is subject-independent
* Whether evaluation is environment-independent
* Whether statistical significance is reported
* Whether results are directly comparable to other papers

Do not compare metrics from different datasets as though they are directly equivalent.

Explicitly flag potentially misleading comparisons.

Create a normalized comparison table and explain which performance claims are genuinely comparable.
