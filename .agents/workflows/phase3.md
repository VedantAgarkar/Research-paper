---
description: Prompt 3: Dataset and realism analysis
---

Analyze every fall-detection paper in the folder specifically from the perspective of dataset quality and real-world validity.

Extract:

* Dataset name
* Dataset source
* Public/private
* Number of videos
* Number of subjects
* Age information
* Gender information if reported
* Number/type of falls
* Number/type of non-fall activities
* Real falls vs simulated falls
* Controlled vs uncontrolled environment
* Indoor/outdoor
* CCTV surveillance environment
* Staircase scenarios
* Multiple people
* Occlusion
* Lighting conditions
* Camera viewpoints
* Resolution/frame rate if reported
* Training/test split
* Cross-subject testing
* Cross-environment testing
* Evaluation protocol
* Dataset limitations

Then classify each paper's evaluation environment as:

1. Highly controlled
2. Moderately controlled
3. Semi-realistic
4. Real-world

Do not judge based on vague claims from the authors. Base the classification on the actual experimental setup.

Identify cases where high reported accuracy may be associated with limited dataset realism.

Provide page/section references for important claims.
